# NutriES Web Store

Web store estatica da NutriES para o dominio `nutries-es.com.br`.

## Contato comercial

`nutriescomercial@gmail.com`

## Deploy

Este projeto pode ser publicado como site estatico no Vercel ou GitHub Pages.

Para GitHub Pages, o arquivo `CNAME` ja define o dominio:

```txt
nutries-es.com.br
```

Para Vercel, adicione o dominio `nutries-es.com.br` ao projeto e aponte o DNS conforme as instrucoes exibidas no painel da Vercel.
